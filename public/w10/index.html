3Make a Health behaviour

Design first: write the properties and the function names before any logic. What does it know, what can it be asked, what can it be told to do.

PartNames
PropertiesMaxHealth (Number, 100), Health (Number, 100), InvulnSeconds (Number, 0.5), InvulnLeft (Number, 0, hidden)
ActionsDamage(amount), Heal(amount)
ConditionsIsDead, IsInvulnerable
ExpressionCurrentHealth
LifecycleonCreated (start at MaxHealth), doStepPreEvents (count the timer down, every frame)

Fast route: import the file

Download Health.json

  1. Project Manager, Extensions, the plus button (Create or search for new extensions).
  2. Choose Import extension and pick Health.json.
  3. Go to step 7 below.

This file was built with GDevelop's own library and its code was tested against a test runtime. Importing it in the editor has not been tried in class, so if it will not import, use the steps below or ask in the clinic.

The steps

  1. Add an extension. Project Manager, Extensions, the plus button, then Create a new extension. Rename it Health straight away (right-click, Rename).
  2. Add a behavior. Open the extension. In the left panel, Behaviors, Add a behavior. Name it Health.
  3. Add properties. The four in the table above. Choose the type for each, and set InvulnLeft to hidden.
  4. Add functions. Add a function and choose Action, Condition or Expression. Parameters 1 and 2 are always Object and Behavior. Add the lifecycle functions onCreated and doStepPreEvents too. If you cannot find them in the menu, import the file and open them there.
  5. Write the logic. In events, or in a JavaScript event as on the next section. A condition must run the action Set condition return value. Forget it and the condition is always false, with no error.
  6. Use a property in scene events. Right-click it and choose Generate expression and action. Properties are private until you do.
  7. Attach it. Open an object, Behaviors tab, Add a behavior, pick Health. Set MaxHealth on each object: 30 on a slime, 400 on a boss. Do it on a second object type.
  8. Use it. In an event, pick the action Damage from the object's Health actions. Then delete the old health events from your scene. If you leave them, the logic runs twice.

Share it: open the extension, the gear icon (Open extension settings), Export extension, Export to a file. You get a plain .json file you can import into your next project.

4The JavaScript inside a behaviour

This is Week 9's JavaScript inside a part you built, and it covers the AFL-3 floor. In the JavaScript event, type Object in the box that picks the objects, or use the getObjects line below. There is no behavior or this variable, so you get the behaviour yourself. A property named Health has _getHealth() and _setHealth(value), spelled exactly like the property. Time is in seconds here: getElapsedTime() is milliseconds, so divide by 1000.

// Every function below starts with this line (it gets the Health behaviour):
const b = eventsFunctionContext.getObjects("Object")[0]
  .getBehavior(eventsFunctionContext.getBehaviorName("Behavior"));

// onCreated  (lifecycle, runs when the object is created)
b._setHealth(b._getMaxHealth());

// doStepPreEvents  (lifecycle, every frame, before your scene events)
const left = b._getInvulnLeft();
if (left > 0) {
  const seconds = runtimeScene.getTimeManager().getElapsedTime() / 1000;
  b._setInvulnLeft(Math.max(0, left - seconds));
}

// Damage(amount)  (action)
if (b._getInvulnLeft() > 0) return;        // still protected
const amount = eventsFunctionContext.getArgument("amount");
b._setHealth(Math.max(0, b._getHealth() - amount));
b._setInvulnLeft(b._getInvulnSeconds());

// Heal(amount)  (action)
const amount = eventsFunctionContext.getArgument("amount");
b._setHealth(Math.min(b._getMaxHealth(), b._getHealth() + amount));

// IsDead  (condition)
eventsFunctionContext.returnValue = b._getHealth() <= 0;

// IsInvulnerable  (condition)
eventsFunctionContext.returnValue = b._getInvulnLeft() > 0;

// CurrentHealth  (expression)
eventsFunctionContext.returnValue = b._getHealth();

These were run against a test runtime, not in a full game. If one fails in your project, read the console message and check the property spelling first.

5Stats as a structure variable

The test: to make every slime 20% tougher, how many places do you edit? If it is more than one, the number lives in the wrong place.

  1. Scene variables, Add a variable, type Structure, Add child. A child for each type, with health and speed inside.
  2. In events: EnemyStats.slime.health.
  3. Or read it in a JavaScript event. Adding a tenth enemy is then a data edit.
// Scene variable EnemyStats (Structure):
//   slime.health = 30   slime.speed = 80
//   boss.health  = 400  boss.speed  = 40
// JavaScript event. Object parameter: Enemy.

const stats = runtimeScene.getVariables().get("EnemyStats");

for (const enemy of objects) {            // every enemy the conditions picked
  const kind = enemy.getVariables().get("kind").getAsString();
  if (!stats.hasChild(kind)) continue;     // a typo is skipped, not created
  const s = stats.getChild(kind);
  enemy.getVariables().get("health").setNumber(s.getChild("health").getAsNumber());
  enemy.getVariables().get("speed").setNumber(s.getChild("speed").getAsNumber());
}

Run it in a sub-event of the event that creates the enemy, so objects holds the new enemy. getChild creates a child that is missing, so a typo makes an empty child instead of an error. hasChild checks without creating one. Scene variables reset when the scene starts.

6Saving, as an idea

  • Save little. Level reached, unlocks, high score, settings. Three numbers and a key is enough for most games here.
  • The actions: Save a value, Save a text, Load a value, Load a text, and the condition Existence of a group. Load puts the answer into a variable you name.
  • First launch has no save. A Load of a missing key leaves your variable as it was, so give it a default first.
  • A whole structure as text: the expression ToJSON(variable) to save it, and the action Convert JSON to a variable to load it.
  • Keep a version number so old saves can upgrade when the shape changes.
  • On the web the browser stores it, per browser. A private window or cleared site data looks like a lost save.

7A state machine for your player

Five booleans is 2 to the power 5, which is 32 combinations. Your game defines maybe six. One variable holding one word makes the impossible states impossible.

  1. One object variable, for example Player.State, holding one word: idle, run, jump, fall.
  2. One named event group per state. Each group starts with its own state check.
  3. Only a state's own group changes away from that state.
  4. Draw it on paper first. If an arrow you need is missing, that transition does not exist in the game either.
GROUP "STATE: run"
  EVENT  Cond: Player.State = "run"
               Key "Space" was just pressed
         Act:  Player.State = "jump"
               Simulate jump key press
  EVENT  Cond: Player.State = "run"
               Player is not moving
         Act:  Player.State = "idle"
  EVENT  Cond: Player.State = "run"
               Player.HurtRequested = 1
         Act:  Player.State = "hurt"

// Hurt comes from a collision, which sits outside every group.
// So the collision only sets Player.HurtRequested = 1 and each group reads it.
// An event group cannot be switched on or off while the game runs.
// Every group starts with its own state check instead.

These are pseudo-events. The real ones are conditions and actions picked from the lists. The Platformer character conditions are Is moving, Is jumping, Is falling and Is on floor, and the action is Simulate jump key press.

Write a behaviour function

Write the JavaScript for the GDevelop 5 behaviour function [Damage(amount)].
Facts you must follow:
- It runs in a JavaScript code event inside an events-based behaviour. There is no "behavior" or "this" variable.
- Get the behaviour with: eventsFunctionContext.getObjects("Object")[0].getBehavior(eventsFunctionContext.getBehaviorName("Behavior"))
- Read an argument with eventsFunctionContext.getArgument("amount")
- A property named Health has _getHealth() and _setHealth(value). Spell it exactly like the property.
- A condition returns with: eventsFunctionContext.returnValue = true or false
- getElapsedTime() is milliseconds. Divide by 1000 for seconds.
- Use only these calls. If you are not sure a call exists, say so.
My properties: [MaxHealth, Health, InvulnSeconds, InvulnLeft].
Give me a plan and your assumptions first, then the code, then how to test it in a preview.

My numbers now: [list each enemy or tower and its numbers].

Turn booleans into a state machine

My player in GDevelop 5 has these booleans: [isJumping, isDashing, isAttacking, isHurt, isDead].
Turn them into a state machine: one variable called State holding one word, and one event group per state.
Give me: the list of states, a table of which state can go to which and why, and what happens when hurt comes from a collision (use a request variable, because an event group cannot be switched off while the game runs).

9Watch out for these

Watch outWhat goes wrongDo this
Behaviour not attachedIts actions are missing for that object, and getBehavior returns undefined.Object, Behaviors tab, Add a behavior. Check the name.
Forgot Set condition return valueThe condition is always false, or an expression returns 0.Set it in every condition and expression.
Property seems missing in scene eventsProperties are private to the behaviour.Right-click it, Generate expression and action.
No objects in your JavaScriptA ReferenceError.Type Object in the box that picks objects, or use getObjects.
Default value against per-object valueYou change the default and old objects keep what they had.Set the value on each object. Check it once on a placed instance.
Cannot see your scene variables inside a functionExtension events only see the extension's own variables.Pass values as parameters, or read them in JavaScript.
Old health events left in the sceneThe logic runs twice.Delete them once the behaviour works.
getChild on a typoIt creates an empty child, so you get 0 and no error.Check with hasChild first.
Load of a missing keyYour variable keeps its old value.Give it a default, and test with Existence of a group.
State changed from two placesOne frame cascades idle, run, jump, because events run top to bottom.Only a state's own group changes it. Use a request variable for hurt.

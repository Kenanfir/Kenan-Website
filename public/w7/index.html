Sound Sources

Where to get sounds, the rule for each, and two small toys. Log every source you use in docs/audio-log.md.

1Make or get sounds

Start with the first one. Twelve sounds in fifteen minutes.

sfxr.me
Make sound effects in your browser. Press a preset (pickup, jump, hit, explosion), then export to download a WAV.
Free. You made it, so you can use it.
Kenney
Ready-made packs of interface sounds, impacts and more.
CC0: free to use, no credit needed.
Freesound
Real recordings: footsteps, doors, rain. You need a free account to download.
Read the licence on every sound. CC0 is free. CC-BY means you must credit the author. CC-BY-NC means no commercial use.
Suno
AI music. Ask for instrumental. Save every prompt.
Free plan: personal, non-commercial use. Paid plan: commercial use for songs made while subscribed. Terms change, so read the current ones before you publish.
Roblox audio
Roblox team: free sounds are in Studio's Toolbox, Creator Store tab, Audio. Uploading your own needs the rights to it.
Upload limits change. Check the upload window.

4Roblox: one scare, four effects

Horror team. Silence, sound, shake, flash. Copy it into a LocalScript in StarterPlayerScripts and change the names to your own objects. Not tested in Studio, so read the Output window if it errors.

local Players = game:GetService("Players")
local RunService = game:GetService("RunService")
local TweenService = game:GetService("TweenService")
local Lighting = game:GetService("Lighting")

local flash = Instance.new("ColorCorrectionEffect", Lighting)

local function scare(ambience, sting)
    ambience.Volume = 0                -- 1. silence
    task.wait(0.3)
    sting:Play()                       -- 2. the sound
    local hum = Players.LocalPlayer.Character:FindFirstChildOfClass("Humanoid")
    local power, conn = 0.4, nil       -- 3. shake, fading out
    conn = RunService.RenderStepped:Connect(function()
        hum.CameraOffset = Vector3.new((math.random() - 0.5) * power, (math.random() - 0.5) * power, 0)
        power *= 0.9
        if power < 0.01 then hum.CameraOffset = Vector3.zero conn:Disconnect() end
    end)
    flash.Brightness = 0.6             -- 4. white flash
    TweenService:Create(flash, TweenInfo.new(0.25), { Brightness = 0 }):Play()
end
